## Why

当前 TypeScript 开放 API 客户端已经提供函数入口和自动化测试，但缺少面向真实业务调用的示例，使用者需要自行拼装参数、认证配置和异步任务流程。补充每个公共函数的真实调用场景，可以降低接入成本，并让用户按需手动执行示例完成联调验证。

## What Changes

- 新增 `examples/` 示例入口，集中展示开放 API 客户端的真实调用方式。
- 为每个公共 API 函数提供一个独立、可读、可手动执行的调用场景。
- 示例使用环境变量读取真实凭据，避免在代码中硬编码密钥。
- 示例只负责写出可执行用法，不在实现过程中主动调用真实开放 API 或运行测试。

### Modified Capabilities

- `open-api-ts-client`: 增加真实调用示例要求，覆盖每个公共函数并明确示例默认不自动执行。

## Impact

- 影响 `examples/` 目录下新增的示例代码。
- 可能影响 `package.json` 的脚本或导出文档，用于提供手动执行示例的入口说明。
- 不改变现有 API 函数签名、请求行为、运行时依赖或测试策略。
