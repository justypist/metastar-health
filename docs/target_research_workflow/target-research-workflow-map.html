Prompt 与流程的对应关系

Stage 3 推荐类 Prompt

决定哪些数据默认参与后续大纲和报告写作，是当前 AI 推荐的核心。

  • P1 推荐适应症
  • P2 内容预评估
  • P3 统一证据评审
  • P4 Section 覆盖评审

Stage 4-5 大纲类 Prompt

控制报告结构、repeat 章节、MoA 展开和跨模块边界。

  • P5 MoA Triage
  • P6 统一大纲审阅
  • Legacy outline fallback

Stage 7 写作类 Prompt

把已推荐数据写成可交付的 slide 内容，并进入最多 3 轮“审阅→重写”闭环。

  • P7 Slide 写作策略
  • P8 正文写作
  • Preclinical / Competition 分支写作

Review / Polish Prompt

负责发现幻觉、重复、图片问题和风格问题，并驱动改写闭环。

  • P9 Review：图片 review / section review / chapter review / global review
  • P10 Rewrite：按审阅意见重写，最多 3 轮
  • P11 Final Style Polish

核心设计价值

这套工作流的核心价值不是“把检索结果简单拼成报告”，而是把同一靶点的历史检索、历史模块数据与历史报告挂载为可复用底座。 当命中历史结果后，每次生成都会在既有证据和报告结构基础上继续进行信息补充、多层 review 与重写迭代； 新增证据会重新进入 AI 推荐、覆盖度判断、写作、审阅和最多 3 轮重写闭环。这样同一个靶点的报告不是一次性交付物， 而是会随着检索积累、证据补充和审阅反馈持续进化的研究资产。
